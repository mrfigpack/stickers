# Mr FigPack — publicação no GitHub Pages

Este pacote já está convertido em um site estático. O arquivo `index.html` fica na raiz e não é necessário instalar nem compilar nada.

1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas deste pacote para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch **main**, a pasta **/(root)** e clique em **Save**.

O endereço costuma ficar no formato `https://seu-usuario.github.io/nome-do-repositorio/`.
